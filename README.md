# 📦 Papa's Invo

Papa's Invo is a simple inventory management application built for small and medium physical stores.

It's designed to help shop owners keep track of what's in stock without needing expensive or complicated software.

## 📊 Current Status

Papa's Invo is in **alpha**. Right now, you can:

- Add item to inventory
- View your current inventory

## 🗺️ Roadmap

Papa's Invo is being actively developed. Planned features include:

- A cashier / point-of-sale system for in-store checkout
- Inventory reports (stock levels, movement, valuation)
- Tax and business growth reports
